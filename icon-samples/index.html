DocBox 图标方案 · 五个方向

全部按 Android 自适应图标网格绘制：108dp 画布，中间 72dp 可见，66dp 安全区。底色取自应用种子色 #6750A4（Material 3 baseline primary 40），前景只用三个色阶——白（onPrimary）、淡紫（primary80/90）、玫瑰（tertiary 一侧的强调色）——保证深色主题与强制主题化（monochrome）都不崩。换遮罩、开安全区，可以看各家的真实裁切结果。

这套图标的 M3E 依据

  • 形体先于装饰：每个方案只有 1–2 个几何母题，24dp 缩到 7 个像素宽时仍然认得出轮廓。
  • 形状张力：圆角矩形（页/匣）配尖角（折角、铅笔尖、井字端头），不是全圆角。
  • 克制用色：一深（紫底）+ 一亮（白）+ 一点缀（粉/淡紫），正好是 expressive 的「rich 但不吵」。
  • 自适应三件套：foreground / background / monochrome 分层；安全区按 66dp 收，圆形、squircle、圆角方三种遮罩都不切内容。

选定之后我会做什么

  • 生成 ic_launcher_foreground.xml / ic_launcher_background.xml（108dp VectorDrawable，路径与这里 1:1）
  • 同步 mipmap-anydpi/ic_launcher.xml 的 monochrome 层（Android 16 起强制主题化，缺了会被系统套一个丑的）
  • 补 round / 各密度 PNG（如仍需要），跑 assembleDebug 验证，再更新 README 里的图标位

每个方案的独立矢量源在同目录 svg/（108×108，可直接拖进 Figma 或 Illustrator）。
说明：预览里的紫色底是两段渐变（#7A63B8 → #5B4596），比纯色在桌面上更有体积感；如果你要严格扁平，把 icBg 换成单色 #6750A4 即可。单色预览（mono）模拟的是系统「主题图标」，它只吃一层着色，所以层次会合并——这也是为什么每个方案都把主形做成实心轮廓。
